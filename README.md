# Hasher

## RU
Я хотел создать что-то простое и полезное, поэтому сделал этот инструмент для быстрого вычисления хэшей MD5, SHA1, SHA256 и SSDEEP файлов, проверки файлов на VirusTotal и верификации цифровых подписей.

## ENG:
I wanted to create something simple and useful, so I made this tool to quickly calculate MD5, SHA1, SHA256 and SSDEEP hashes of files, check files on VirusTotal, and verify digital signatures.
